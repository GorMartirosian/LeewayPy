# Constraint Solver Prototype Setup

## 1. Clone the repository

```bash
git clone https://github.com/GorMartirosian/LeewayPy.git
cd LeewayPy
```

## 2. Create and activate a virtual environment

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## 3. Install dependencies

```bash
pip install pygame sympy numpy
```

## 4. Run the program

```bash
python test.py
```
